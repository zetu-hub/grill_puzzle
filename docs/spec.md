## 1. ゲーム概要

| 項目 | 内容 |
|------|------|
| ジャンル | カジュアルパズル |
| プラットフォーム | スマホブラウザ（縦画面） |
| 画面解像度 | 375 × 812px（FITスケール） |
| テーマ | 焼き鳥・BBQ・串焼き |
| ゲーム目標 | 制限時間内に指定数の食材を消す |
| 1プレイ時間 | 最大5分 |

### コア体験
複数の焼き網（グリル）に置かれた食材を、グリル間で移動させて同じ種類を3つ揃えて消す。消えたグリルには皿から次の食材が自動補充される。

## 4. ゲームルール

### 4-1. ゲーム開始時の初期状態

- 12個のグリル（3列×4行）を生成
- 各グリルにランダムで **1〜3個** の食材を配置
- 各皿にランダムで **1〜3個** の食材を配置
- タイマー：5分（300秒）からカウントダウン開始
- スコア：0、消去数：0 からスタート

### 4-2. 消去ルール（マッチ判定）

```
同じ食材IDが 3個 同じグリル内に存在する → 消去
```

- 判定タイミング：食材がグリルに追加されたとき（移動後・皿補充後）
- 消去は自動（プレイヤー操作不要）
- 3個ちょうど消える（4個以上ある場合も3個単位で消去）
- 消去後のスコア加算：**+150点**（3個1セット）

### 4-3. 皿からの自動補充

消去によってグリルが **空（0個）** になった場合：

1. 250ms 待機（演出の間）
2. その皿の食材（1〜3個）をすべてグリルへ移動
3. 新しい皿を生成（食材数：1〜3個ランダム）
4. 180ms 待機後、補充されたグリルに対してマッチ判定を実行（連鎖チェック）

```
消去
  └→ グリル空？
       ├→ Yes: 皿補充 → 連鎖チェック
       └→ No:  そのまま終了
```

### 4-4. クリア条件

```
cleared >= GOAL（30個）
```

- 達成した瞬間にアニメーション停止 → 500ms後にクリア画面を表示

### 4-5. 時間切れ条件

```
timeLeft <= 0（300秒経過）
```

- タイマーイベントを停止 → TIME UP 画面を表示

### 4-6. 移動の制限

- 移動先グリルが満杯（3個）の場合 → 移動不可
- 視覚的フィードバック：赤枠フラッシュ（350ms）

## 5. 操作仕様

### タップ操作（2ステップ方式）

#### ステップ1：食材を選択

- 食材アイコン（32×32px）をタップ
- 選択された食材：白いグロー（不透明度45%）が付く
- 同じグリルをタップし直す → 選択解除
- グリル外をタップ → 選択解除

#### ステップ2：移動先を指定

- 別のグリル（本体エリア or 食材スロット）をタップ
- 移動先が空きあり → 食材を移動、マッチ判定へ
- 移動先が満杯 → 赤枠フィードバック、選択解除

#### 判定優先順位（タップ時）

```
1. 食材スロット（食材が存在するスロットのみ）
2. グリル本体（空のグリルや空きエリア）
3. 範囲外 → 選択解除
```

#### アニメーション中の操作

- `isAnimating = true` の間はすべてのタップを無視

## 8. ゲーム進行フロー

```
[create]
  ├─ grills[12] 初期化（foods: 1〜3個, plateFoods: 1〜3個）
  ├─ HUD描画
  ├─ グリル描画
  ├─ アイテムバー描画
  └─ タイマー開始（1秒ごと）

[プレイ中ループ]
  ├─ タップ入力 → 食材選択 or 移動
  │    └─ 移動成功 → _checkMatch(toIdx)
  │         ├─ マッチなし → 終了
  │         └─ マッチあり → フラッシュ演出
  │              └─ 消去 → グリルが空？
  │                   ├─ Yes → 250ms後 皿補充 → 180ms後 _checkMatch（連鎖）
  │                   └─ No  → 終了
  └─ 1秒ごと → timeLeft--
       ├─ timeLeft <= 0 → TIME UP
       └─ cleared >= GOAL → CLEAR

[終了]
  ├─ CLEAR: スコア表示 + リトライボタン
  └─ TIME UP: 消去数表示 + リトライボタン
```
