# グリルパズル 最新仕様

更新日: 2026-05-16
対象: Phaser 3 / スマホ縦画面 / GitHub Pages 公開想定

## ゲーム概要

グリル上の食材をドラッグまたはタップで別のグリルに移動し、同じ食材を3個そろえて消すパズルゲーム。制限時間内にステージ内の食材をすべて消すとレベルクリア。

## 基本画面

- 解像度は 375 x 812 を基準にする。
- 上部にレベル、残り時間、消去数を表示する。
- 中央に 3列 x 4行、最大12個のグリルを表示する。
- 下部の丸ボタンにお助けアイテムを4種類表示する。
- レベルによって使えるグリル数が変わり、使えないグリルには蓋を表示する。
- 右上の丸ボタンは一時停止ボタンとして機能する。

## 操作

- 食材をドラッグして別のグリルへ移動できる。
- ドラッグ中の食材は指先と同じ位置に表示する。
- 食材をタップして選択し、別グリルをタップして移動することもできる。
- 移動先グリルが満杯の場合は移動できない。
- ドラッグで置く場合は、ポインタ位置に近い左・中央・右のスロットへ置く。
- 指定したスロットが埋まっている場合、別スロットへ自動移動せず配置不可にする。
- 食材が補充されたとき、空いたスロット位置は左詰めにせず保持する。
- 一時停止中は RESUME、RETRY、TITLE を選べる。

## 食材と補充

- 食材は最大8種類。
- 各レベルの消去数に合わせて、同じ食材3個で1セットの在庫を作る。
- 初期配置や補充時点では、同じ食材が3個そろった状態にならないようにする。
- グリルが空になったら、まず下の皿から次の食材を補充する。
- 皿も空で在庫が残っている場合は、在庫から新しい食材を補充する。
- 最終的に在庫、グリル、皿の食材がすべてなくなるとクリア。

## マッチとクリア

- 同じグリル上に同じ食材が3個あると自動で消える。
- 1セット消すたびに消去数が1増える。
- クリア条件は画面上と在庫内の食材がすべてなくなること。
- 時間が0になるとタイムアップ。

## お助けアイテム

各レベルでそれぞれ1回だけ使用できる。どれか1つでも使った場合、そのレベルの星評価は必ず星1になる。アイコンは生成画像を使用し、各アイコンの下に短い説明を表示する。

| 表示 | 名前 | 効果 |
|---|---|---|
| S | MIX | グリル上の食材をシャッフルする。シャッフル直後に3個そろう配置は避ける。 |
| R | UNDO | 直前の有効な移動を1手戻す。 |
| H | OPEN | 蓋つきグリルを1つ開放し、食材と皿を補充する。 |
| F | +10s | 残り時間を10秒増やす。 |

## 星評価

クリア時に星1から星3で評価する。

- お助けアイテムを使用した場合は必ず星1。
- 星3: お助け未使用、残り時間が制限時間の35%以上、手数が消去数 x 2 以下。
- 星2: お助け未使用、残り時間が制限時間の15%以上、手数が消去数 x 3 以下。
- 星1: 上記以外。
- 星の表示には生成画像の星アイコンを使用する。

## 結果画面

レベルクリア後、次のレベルへ進む前に結果画面を表示する。

- 星評価
- 手数
- 残り時間
- お助け使用時は星1固定であること
- 次レベルへ進むボタン、または最終レベル後のタイトルボタン
- 次レベルへ進む前の結果画面から TITLE でタイトルへ戻れる。
- タイムアップ時のリトライ画面からも TITLE でタイトルへ戻れる。

## 記録画面

タイトル画面の RECORDS から記録一覧を表示できる。タイトル画面の LEVELS からレベル選択画面を表示できる。

- レベルごとの最高星評価
- その記録時の手数
- その記録時の残り時間
- 記録は localStorage に保存する。
- より高い星、同じ星なら残り時間が多い記録、さらに同じなら手数が少ない記録を保存する。
- Lv.1 は常に選択可能。
- クリア済みレベルと、その次のレベルを選択して開始できる。

## 実装ファイル

- `index.html`: エントリーポイント。
- `src/main.js`: Phaser ゲーム設定。
- `src/config/foods.js`: 食材定義。
- `src/logic/MatchLogic.js`: 3個そろい判定と消去処理。
- `src/scenes/GameScene.js`: タイトル、記録画面、ゲーム本体、結果画面。
- `src/assets/foods/*.png`: 食材イラスト。
- `src/assets/ui/*.png`: お助けアイテムと星評価の生成画像。
